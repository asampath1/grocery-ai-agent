## Record format

Each item follows the same structure:

- **Question:** what was asked
- **My first answer:** word for word, typos included
- **Coach challenge:** what was pushed back on, and why
- **My revised answer:** word for word
- **Outcome:** what changed, with a link to the DEC entry
