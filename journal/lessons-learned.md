# Lessons Learned

Durable lessons distilled from the daily journal. Newest first.

- **2026-10-11:** Walking failure scenarios through a design finds gaps that drawing boxes doesn't. Logging isn't alerting.
- **2026-10-11:** Treat model output, including tool arguments, as untrusted input.
- **2026-10-08:** A "not found" error from an API can be a permissions problem in disguise. Check token scopes first.
- **2026-10-08:** Before adding an AI component, ask what it does that plain code can't. That keeps the AI's role honest and makes the design easier to explain.
- **2026-10-08:** Put the data-acquisition risk early in the plan. The schema and the rest of the system depend on what real sources actually return.
